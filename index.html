Help / references

This fan-made editor follows the slanted, white-bordered character cut-in and split DOMAIN / EXPANSION lettering visible in Jujutsu Shenanigans gameplay. See also the Gojo animation reference. Built-in scenes and characters are original stylized placeholders, not extracted game assets. Upload your own character render for a closer match.

Unzip the frames and import the numbered PNGs into your video editor at your selected FPS. PNGs preserve transparency; video uses a dark background and the browser's supported WebM or MP4 format. Video records in real time: keep this tab visible. Save project downloads a JSON file including your uploaded images. Open this HTML directly in a modern desktop browser; no hosting, account, libraries, or connection required.

How to use your domain in JJS

70-second illustrated walkthrough · on-screen instructions · no audio. This is not an in-game recording.

The template is optional. You do not have to paste it! You can build your skill from scratch in Skill Builder: create Visual nodes set to Overlay, assign your uploaded frame textures in order, and place Wait nodes between frames. Start with 1 ÷ FPS seconds between frames, adjust effect lifetimes, and test. Use your own frame count and add branches only if needed.

Follow these steps

  1. Finish your domain. If using the optional template, start with 3 seconds at 12 FPS, then click Download frames (.zip). This gives 36 PNGs.
  2. Extract the ZIP and upload all numbered PNG frames to Roblox as image/decal assets using Creator Hub or Studio. Wait for processing and moderation.
  3. Copy each uploaded frame’s image/texture asset ID. Keep the IDs ordered from domain_0000.png to domain_0035.png. Use the actual texture/image ID accepted by JJS, not the asset page URL.
  4. Join your Jujutsu Shenanigans private server, enter Build Mode, place a Character Block, and open Configure. Edit the relevant skill to open Skill Builder.
  5. Choose either route: build your own Overlay/Wait sequence from scratch, or use the optional template. To use the template, copy the complete code below. Paste it into the code/import editor and apply/import it. If that editor rejects this format, use the Character Block Configure menu’s import/clipboard control, then edit the imported domain skill. This is JJS configuration data, not a Lua script.
  6. If using the template, replace EVERY Overlay Visual’s Texture with your own uploaded video-frame texture ID. Go in playback order, and repeat the replacements in the Freeze branch.
  7. For 12 FPS, start with 0.0833 seconds between frames instead of the supplied 0.1-second waits. Review effect lifetimes and the final frame too. Test both sequences, adjust the effects/gameplay, and save/export your character in JJS. You can modify and improve the template.

For the supplied template only, both sequences need updating: 36 Overlay Visuals in the main sequence + 36 in Branch → Freeze = 72 texture fields. Reuse your same 36 uploaded IDs in both paths. If your export has a different frame count, add/remove matching Overlay and Wait nodes in both sequences.
